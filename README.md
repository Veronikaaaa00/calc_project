# calc_project

Практическая работа 1: маршрутизация, формы и URL как состояние.

Приложение на Flutter: калькулятор и конвертер валют.
Переходы через `go_router`, результат передаётся параметрами адреса.

## Запуск

```bash
flutter pub get
flutter run
```

## Проверки

```bash
flutter analyze
flutter test
```
